# Changelog

Notable changes to Valoroulette are documented here.

## [0.1.1]

### Added

- Filter the roulette by one or more agent roles, or exclude and restore an entire role.
- Exclude an agent by clicking their portrait on the roulette.
- Check for stable GitHub releases automatically at startup; show an update action only when a newer release is available.
- Choose a secret target in the menu and select it with Ctrl+click or Alt+click on Spin.
- Hide or show the role section from the menu.
- Support English, Spanish, French, German, Portuguese, Simplified Chinese, Japanese, Korean, and Italian.

### Changed

- Reorganized the menu and main layout, keeping the roulette beside the excluded-agent and role panels.
- Persist custom agent images and user settings across app updates.
- Improved the roulette pointer animation and responsive window sizing.

## [0.1.0] - Initial release

- Released the Windows desktop roulette for randomly selecting VALORANT agents.
- Added agent exclusion and restoration, custom agents with PNG portraits, and secret target mode.
- Included a multilingual interface and GitHub release update support.
